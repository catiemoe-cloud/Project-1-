In this video, I will be showing how my Apple valuation model works, how someone can run it, and the validation I completed. This project is for a buy-side investment committee deciding whether to initiate Apple as of September 17, 2026.

Looking at the repository, the README explains the decision, sources, how to run the project, and limitations. Source code is in src, research is in research, visible output is in output, and final documents are in docs.

[Show the run commands in `README.md`.]

To run the project, a user needs Python 3.9 or later. There are no third-party packages, credentials, or API keys. The analysis script creates visible output, so a grader can see inputs, valuation date, results, and checks without running the model.

[Open `src/apple_fcff_model.py` at the inputs and assumptions.]

Next, looking at the model itself, it starts with Apple’s fiscal-year 2025 audited balance sheet and forecasts FY2026E through FY2030E. My base assumptions are 6% revenue growth, 47% gross margin, 15% operating expenses as a share of revenue, 3% capex, 9% WACC, and 2.5% terminal growth.

FCFF is NOPAT plus depreciation, less capex and the change in operating net working capital. For every year, assets must equal liabilities plus equity, and cash flow must match the balance-sheet change in cash. If either one does not tie, the check fails.

[Run `python3 src/apple_fcff_model.py` and show the results.]

When I run the model, the base value is $131.61 per share, and both statement checks are zero for all five years. My low, base, and high cases are $87.07, $131.61, and $185.85. The WACC and terminal-growth sensitivity ranges from $109.06 to $167.57. My reverse-DCF check could not reach $337 with constant growth from negative 10% to 30%, keeping the other inputs fixed. This shows the expectations needed under this model.

[Show `docs/wacc-build.md` and the bridge output.]

For the enterprise-to-equity bridge, I added $146,517 million of cash and marketable securities, subtracted $84,344 million of debt, and divided by 14,594.18 million shares. The documented WACC build is 9.45%; the model uses a rounded 9% input and shows the 8% to 10% range.

[Run `python3 src/analysis.py` and show `output/visible_output.json`. Then run `python3 src/peer_valuation.py` and show `research/peer-policy.md`.]

The analysis script creates visible output from the same model, so I am not manually typing results into a report. For the peer cross-check, I used Microsoft and Alphabet based on a policy created before selecting them. Their P/E results imply $206.86 to $239.69 per share. I do not average them into the DCF because their businesses differ from Apple.
