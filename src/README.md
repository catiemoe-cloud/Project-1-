# Runnable Source

Run these commands from the repository root:

```bash
python3 src/apple_fcff_model.py
python3 src/analysis.py
python3 src/peer_valuation.py
python3 src/app.py
```

`apple_fcff_model.py` is the final FCFF engine; `analysis.py` writes the visible output; `peer_valuation.py` provides the peer cross-check; and `app.py` starts the local product demo.
